\doxysubsection{Descrizione dettagliata}
Rappresenta una pubblicità distribuita dal cinema nei canali appropriati. 

Classe astratta derivata dalla classe base astratta \doxylink{class_media}{Media}. Una pubblicità riporta in più il numero di proiezioni giornaliere del media nei canali adatti del cinema.
